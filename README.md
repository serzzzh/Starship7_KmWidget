# Starship 7 - Range Widget (KmWidget)

Проект виджета для Android-автомагнитолы Geely Galaxy Starship 7 (P145), который отображает расчетный остаток пробега на основе реального расхода (батареи и топлива) за последние N минут или X километров.

Ссылка на GitHub-репозиторий: [https://github.com/serzzzh/Starship7_KmWidget](https://github.com/serzzzh/Starship7_KmWidget)

## Описание
Виджет использует `CarPropertyManager` (Car API) для чтения системных параметров автомобиля:
- Текущий одометр
- Текущий заряд батареи (%)
- Текущий уровень топлива (%)

Данные собираются фоновым сервисом в локальную базу SQLite. При обновлении виджета происходит расчет реальной эффективности (км на 1% заряда/топлива) и вычисление расчетного остатка хода.

## Установка и сборка

### Локальная сборка (требуется ADB)
Проект настроен на сборку Privileged-приложения.
```bash
# Установка/Обновление на устройстве (подключенном по ADB)
./deploy.sh
```

### Сборка через GitHub Actions
При любом пуше в ветку `main`, GitHub автоматически собирает APK-файл. 
Скачать его можно во вкладке **Actions** -> Выбрать последнюю сборку -> **Artifacts** -> `kmwidget-apk`.
